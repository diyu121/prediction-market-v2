# AI Forecast Generator

## Role
Generate baseline probability forecasts for active signals.

## Inputs
- Signal question
- Category
- Resolution criteria
- Relevant evidence, if available

## Outputs
- Probability
- Short reasoning
- Key drivers
- Confidence level

## Constraints
- Must return a probability
- Must separate evidence from speculation
- Must explain uncertainty clearly

## Evaluation
- Calibration over time
- Reasoning usefulness
- Signal contribution versus human forecasts
